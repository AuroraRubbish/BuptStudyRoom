# 大邮分类集

《大邮分类集》以《大邮数学集》收录的相关往年题为基础，按教材章节与知识点重新编排，为每一章节配备了考点分类及常考题型，并附上（由AI生成的）详细解析。整理这份资料的目的是便于同学们节约翻找同类题型的时间，以更高效的学习、推导和查漏补缺，为期中、期末备考提供一点帮助。

本项目为独立维护的非官方分类整理。

表中数字为对应 PDF 的实际页数。每科四个文件，均为 Demo 1.2.0。

- `electronic`：紧凑电子合册，便于阅读和批注。
- `electronic-workbook`：留白电子合册，提供题后书写区。
- `exercises-print`：打印习题册，提供题后书写区。
- `solutions-print`：打印解析册，与习题册按题号对应。

两种电子版提供题目与解析双向跳转、目录链接和书签。打印分册在知识点标题下列出另一册的正文页码，按双面打印调整页码位置。

工科数学分析按《工科数学分析基础》上下册编排，线性代数按《线性代数与几何》编排。题面以《大邮数学集》Release 1.4.3 为底稿，补入 Release 1.5.0 新增试卷及已核实的订正。
